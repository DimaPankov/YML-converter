# Проверка XML RLSBASK001

Проверено 8 сентября 2026 года. Исходный пример сохранён в `rls-user-original.yml`.

XML синтаксически корректен. Разбор с учётом пространства имён портала находит **1 предложение**, ID `RLSBASK001`. Это проверка структуры XML, а не подтверждение принятия порталом.

| Проверка | Результат |
|---|---|
| Фото `https://rls.com.ru/test-import/RLS-BASK-001.png` | GET вернул HTTP 404 и `text/html`, а не изображение. Требуется рабочая публичная ссылка на JPEG/PNG. |
| Страна происхождения `oksm` | Отсутствует; указана обязательной в таблице 4, стр. 17 предоставленной инструкции. Нужно реальное значение страны производства. |
| Курьерская доставка `delivery` | Отсутствует; обязательна по таблице 4, стр. 17. Указать `true` либо `false` по фактическим условиям. |
| Категория | `ppCategory=1` — ссылка на справочник портала. Категория `id=1` из блока `categories` связывается через `categoryId=1`. Если цифра 1 взята из собственной категории, следует заменить `<ppCategory>1</ppCategory>` на `<categoryId>1</categoryId>` и сопоставить собственную категорию с категорией портала при импорте. Действительность ID 1 в справочнике портала не установлена. |
| Видимость | `isVisibleToStateCustomers=false` и `isAvailableToIndividuals=false`: отключена доступность для обеих групп покупателей. Это отдельный вопрос публикации; не доказано, что он вызывает «0 товаров» при импорте. |
| URL магазина | Содержит перевод строки. Рекомендуемая запись: `<url>https://rls.com.ru</url>`. Не установлено, что это причина отказа портала. |
| Валюта RUR | Допускается вместе с RUB по стр. 11 инструкции. Менять только из-за кода RUR не требуется. |
| Пять характеристик | Присутствуют; минимум четыре выполнен. |
| НДС VAT_5 | Нужна проверка значения по справочнику портала и включённой загрузки ставок. Без справочника код не подтверждён и не объявляется ошибочным. |
| available=false | Допустимое значение «на заказ», само по себе не ошибка формата. |

Публичную XSD-схему скачать не удалось из-за ошибки соединения с сервером портала. Полная XSD-валидация не выполнена. Точную причину результата «0 товаров» можно установить по отчёту импорта портала.

Для исправленного файла нужны фактическая страна происхождения, условия курьерской доставки, рабочая ссылка на фото и подтверждение способа категоризации. Эти сведения не подставляются предположительно.
